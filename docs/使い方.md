# Nestの使い方

よく使うファイル・フォルダー・Webリンクをデスクトップのパネルにまとめます。
元のファイルは移動・削除せず、登録だけを管理します。

## はじめに

Windows 11 x64 / .NET Framework 4.8以降を対象にしています。

作者は小窓製作所です。この版はコード署名を付けずに配布する方針です。

ZIPをすべて展開し、Nest.exeを開きます。EXEだけを別の場所へ移さず、
icons、利用条件、publisher.txtを一緒に保管してください。
セキュリティ上の警告が出た場合は、安全機能を無効にせず、配布元を確認してください。

## 基本操作

1. ファイルやフォルダーをパネルにドロップして登録します。
2. 項目をダブルクリック、または矢印で選びEnterで開きます。
3. 項目を選択してCtrl+Shift+R、またはF2で表示名を変更します。元のファイル名は変わりません。
4. Deleteで登録を解除します。Ctrl+Zで元に戻せます。
5. パネル上部をドラッグして移動し、辺・四隅でサイズを変更します。

Ctrl+Alt+Nでパネルへ移動。F6で領域移動、Ctrl+Tabでタブ切替、
Ctrl+Fで全パネルの登録を検索、Shift+F10でメニューを開きます。
Ctrl+C/X/Vは登録のコピー／切り取り／貼り付けです。

長い名前はパネルのメニューから「表示形式」→「一覧」で確認できます。
設定の「項目名の大きさ」で文字を拡大できます。
外観は自動保存、キー割当は「保存」で確定します。キーの変更は破棄もできます。

## パネルが見えないとき・終了

Ctrl+Alt+N、または通知領域のNestから「すべて表示」を選びます。
画面外へ出た場合は設定の「画面内に整列」を使います。
パネルの×や閉じる操作では非表示になる場合があります。
アプリを終了するには通知領域のNest→「Nestを終了」を選んでください。

## 保存とバックアップ

この配布版はportable.txtを同梱するポータブル版です。
EXEと同じフォルダーのdataへ保存します。書込み可能な個人フォルダーで使ってください。
portable.txtを付けず、隣に既存dataもない導入では、ユーザーごとの
LocalAppData\Nest\dataへ保存します。既存dataがある場合はその場所を維持します。

「保存と復旧」から配置を書き出し、読み込み、過去の配置を選択できます。
履歴画面で件数・容量を確認できます。選んだ古い履歴は削除せず、
data\history\archiveへ移して保管できます。そこから「設定を読み込む」で復元できます。
設定のJSONには登録名や個人フォルダーのパスが含まれます。
別PCへ持ち出す際はiconsも保管し、リンク先が変わった場合は修正してください。
履歴は元のファイルそのものをバックアップしません。

## この版の起動方法

Nest.exeを直接ダブルクリックしてください。更新プログラムは使いません。
旧版とは起動時の識別、保存フォルダー、自動起動の登録を分けています。
最初は新しい配置で起動します。旧版の設定を使いたい場合は、旧版で設定を書き出し、
この版の「保存と復旧」→「設定を読み込む」から取り込めます。
同時起動中は共通のショートカットキーが競合するため、使い始める際は旧版を終了してください。

## アンインストール

設定の「Windowsサインイン時に自動起動」を解除し、通知領域から終了します。
必要な配置とiconsをバックアップしたうえで、Nestのフォルダーをごみ箱へ移します。
ユーザー別保存モードでは、設定に表示される保存フォルダーも別に保管・整理してください。
元のファイルやフォルダーを片づける必要はありません。

### 操作部分を大きくする
設定の「外観」で「スクロールバーとサイズ変更の操作範囲を広げる」を選ぶと、つかみ幅を広げられます。文字の大きさも100～150%に調整できます。

## F2がミュートになる場合

項目を選んで **Ctrl+Shift+R** を押してください。Nestの表示名だけを変更します。ミュートの設定は変更不要です。右クリックの「表示名を変更」も使えます。Ctrl+Shift+Rを別の操作に割り当てた場合は、その設定が優先されます。
