# Nest 2.0.0 の使い方

よく使うファイル・フォルダー・Webリンクを、デスクトップのパネルにまとめます。元ファイルを動かさず、登録だけを管理します。

## 起動と終了

Windows 11（64ビット）／.NET Framework 4.8以降に対応します。ZIPをすべて展開し、書き込み可能な個人フォルダーからNest.exeを開いてください。iconsと同梱文書も一緒に保管します。

パネルへ移るにはCtrl+Alt+N。通知領域のNestから「すべて表示」も使えます。終了は通知領域の「Nest を終了」です。作者は小窓製作所です。コード署名はありません。Windowsの警告が出た場合は配布元と端末の管理ルールを確認してください。

## 基本操作

1. ファイルやフォルダーをドロップするか、パネル上部の「＋」から登録します。
2. 項目をダブルクリック、または矢印で選びEnterを押して開きます。
3. 選択済みの名前をクリックすると表示名を編集できます。Ctrl+Shift+R、F2、右クリックの「表示名を変更」でも編集できます。元のファイル名は変わりません。
4. Deleteで登録を外し、Ctrl+Zで取り消します。元ファイルは削除されません。Ctrl+Yはやり直しです。
5. パネル上部をドラッグして移動し、辺・四隅でサイズを変えます。近くのパネルへ吸着し、離す方向へ動かすと解除します。

Ctrl+C/X/Vは登録のコピー／切り取り／貼り付けです。F6で領域移動、Ctrl+Tabでタブ切り替え、Shift+F10でメニューを開きます。

## 検索してすぐ開く

パネル上部の「検索」またはCtrl+Fで、全パネルの名前とリンク先を検索できます。結果を選びEnter・ダブルクリック・「開く」で直接開きます。Ctrl+Enterまたは「パネルで表示」で登録場所を確認できます。最大200件を表示し、それ以上は検索語を追加して絞り込みます。

## パネル・タブの整理

タブは文字サイズを維持し、固定の最低幅をなくして上下左右の余白を最小限にしました。パネルの「…」メニューは次のように整理しています。

- 「追加」：ファイル・アプリ、フォルダー、Webリンク、登録の貼り付け。
- 「パネルの整理」：新規、コピー、名前変更、タブ追加、内容に合わせる、サイズを合わせる、配置ロック。
- 「表示」→「表示形式」：アイコン／一覧。長い名前は一覧で確認できます。
- 「ワークスペース」：用途別に表示パネルと配置を切り替えます。
- 「リンクの点検と修正」：接続状態・重複登録・移動後の登録先を確認します。

空白クリックで選択を解除できます。パネルのコピーは全タブ・登録を複製します。コピー後の登録は独立して編集でき、元ファイルは複製しません。

1タブが120件を超える場合は「前へ」「次へ」でページを切り替えます。検索や矢印キーでページ外の項目を選ぶと、そのページへ移動します。登録は全件保持され、Ctrl+Aは現在のタブ全体が対象です。

## ワークスペース

「…」→「ワークスペース」→「ワークスペースを管理…」、または設定の「ワークスペース」を開きます。表示したいパネルを選び、名前を入力して「新しく保存」を押します。保存時の配置と表示するパネルが記録されます。

一覧から選び「切り替え」を押すと、その用途のパネルだけを表示します。利用中の位置・サイズ・選択タブ・折りたたみ状態は自動保存されます。表示対象を変える場合は一覧から選び、チェックを変更して「選んだ設定を更新」を押します。「すべてのパネル」で全パネルへ戻れます。

ワークスペース間で登録内容は共有します。切り替えてもファイルや登録は削除されません。利用中に新規作成・コピーしたパネルは現在のワークスペースに加わります。最大100件です。

## リンクが開けないとき

エラー画面から「再試行」「リンク先を変更」「場所を開く」を選べます。「場所を開く」はファイル・フォルダーの親フォルダーを開きます。Webリンクには使えません。

「リンクの点検と修正」では、利用可能／見つからない／状態不明を表示し、重複登録も示します。ネットワーク切断、権限不足、応答待ちを単純なリンク切れとは扱いません。Webリンクへは接続せず「未点検」と表示します。元ファイルや登録を自動削除することはありません。点検は「中止」で停止できます。

「フォルダーを一括変更…」で変更前後のフォルダーを絶対パスで指定し、「変更内容を確認」で対象を確認してから適用します。一覧で項目を選択していると選択分、未選択なら全登録が対象です。登録先だけを変更し、元のファイルは移動しません。Ctrl+Zで取り消せます。変更先の存在は適用後に再点検してください。

## 設定の保存

外観は変更すると自動保存されます。キー設定だけは「キー設定を保存」で確定します。このボタンはキーボード操作の画面だけに表示されます。未保存のキー変更は破棄できます。文字サイズは100～150%に変更でき、スクロールバーとサイズ変更の操作範囲も広げられます。

## 配置の復旧

設定の「保存と復旧」から「過去の配置から復元…」を開きます。選択するとパネル名・タブ数・登録数と、現在との差（追加／登録解除／名前・リンク・アイコンの変更）を確認できます。復元直前にも確認を表示し、現在の配置を履歴に残します。

「名前を付けて現在の配置を保存」で「整理前」などの名前を付けられます。履歴は自動削除しません。選んだ履歴を「別に保管」するとhistory\archiveへ移します。必要な場合は「設定を読み込む」から戻せます。直近100回の登録操作はCtrl+Zで取り消せますが、再起動後は履歴を使います。

## 引っ越しバックアップ

「保存と復旧」→「引っ越しバックアップを書き出す…」で、配置・設定・ワークスペース・使用中の追加アイコンを一つの.nestbackupファイルに保存します。元のファイル・フォルダーの内容、アプリ本体、過去の履歴は含みません。登録名や個人フォルダーのパスが含まれるので、共有先に注意してください。

別PCではNestを配置し「引っ越しバックアップを読み込む…」で内容を確認して復元します。同名で内容が異なるアイコンは別名で保存し、既存アイコンを上書きしません。フォルダーの場所が変わった場合は「フォルダーの場所を一括変更…」を使い、リンクを再点検します。従来のJSON書き出し／読み込みも引き続き利用できます。

## 拡張ディスプレイ

外部ディスプレイを外すと、パネルを残った画面へ一時退避し、再接続すると元の画面・位置へ戻します。切断中に終了・再起動しても元の配置を保持します。退避中に動かしても復帰先は変わりません。本体側を新しい配置先にする場合は、外部画面を接続した状態で本体側へ移動してください。

非表示・折りたたみ・配置ロックの状態を維持します。ドックや端子の変更によりWindowsが別の画面として認識すると、元の位置へ戻らない場合があります。別PC、異なる表示倍率、物理的なディスプレイ抜き差しは公開前に確認してください。

## 保存場所・更新・アンインストール

ポータブル版はNest.exeと同じフォルダーのdataへ保存します。portable.txtも既存dataもない導入ではLocalAppData\Nest\dataを使います。更新前にNestを終了し、dataとiconsを保管してください。通常は実行ファイルと同梱文書を入れ替え、既存dataと追加アイコンを維持します。

削除するときは設定の自動起動を解除し、通知領域から終了します。必要な配置とiconsを保管してからNestのフォルダーをごみ箱へ移してください。元のファイルやフォルダーを削除する必要はありません。
