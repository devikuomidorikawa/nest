# Nest

**よく使うファイル・フォルダー・Webリンクを、デスクトップの小さなパネルに。**

Nestは、Windows向けの無料デスクトップ整理アプリです。用途ごとにパネルやタブを分けて、必要なものをすぐに開けます。作者は **小窓製作所** です。

> 現在は公開準備中です。配布ファイルは最終確認後に、このリポジトリの **Releases** に掲載します。

## できること

- ファイルやフォルダーをドラッグ＆ドロップして登録
- Webリンクの登録と起動
- パネル・タブで分類、全パネルから検索
- パネルの色・透明度・文字サイズ・表示形式の調整
- キーボード操作、登録操作の取り消し
- 配置の書き出し・読み込み・履歴からの復旧
- 拡張ディスプレイ切断時のパネル退避と、再接続時の配置復元（1.9.2以降）

登録名の変更や登録解除は、元のファイルの名前や内容を変更しません。履歴に保存するのはNestの配置や設定で、元ファイルのバックアップではありません。

## 対象環境

Windows 11（64ビット）／.NET Framework 4.8以降。画面と説明は日本語です。

## ダウンロードと起動

公開後は、このページの **Releases** から `Nest-1.9.2-ja.zip` をダウンロードしてください。GitHubが自動で表示する「Source code」のZIPにはアプリ本体は入っていません。

1. ZIPをすべて展開します。
2. 書き込み可能な個人フォルダーへ置きます。
3. `Nest.exe` を開きます。`icons` や同梱文書も一緒に保管してください。

この版にはコード署名がありません。Windowsで発行元不明などの警告が表示されたり、管理されたPCで実行が制限されたりする場合があります。配布元と端末の管理ルールを確認してください。保護機能を無効にする手順は案内していません。

## 最初の3操作

1. ファイルやフォルダーをパネルへドロップして登録します。
2. 項目をダブルクリックして開きます。
3. 不要な登録は選択してDeleteで解除します。Ctrl+Zで取り消せます。

パネルが見えないときは **Ctrl+Alt+N**、または通知領域のNestから「すべて表示」を選びます。終了するには通知領域のNestから「Nestを終了」を選んでください。

詳しくは [使い方](docs/使い方.md) と [よくある質問](docs/よくある質問.md) をご覧ください。
